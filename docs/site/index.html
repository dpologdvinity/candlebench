Do classic candlestick patterns have a real intraday edge?

candlebench turns every signal from 20 textbook patterns into a mechanical trade. It charges each trade the spread quoted at that time of day, and compares it with random entries that take the same risk. A pattern counts only if it beats those entries, makes money after costs, and holds up on later dates it was not chosen on.

The answer

The run covers two years of 1-minute bars for 50 liquid US stocks: 19,239 pattern trades at a quoted 1.85 bps per leg. No pattern has an edge. None has positive expectancy after costs, and none beats its own matched random entries even before costs once multiple comparisons are corrected for.

A second run at 5-minute, 15-minute and 1-hour bars over the same two years (61,297 pattern trades at 1.68 bps per leg) finds the same: no pattern beats its matched random entries at any of the three timeframes.

How the method was checked

A method that finds edges in noise is not measuring anything. On a synthetic random walk, comparing patterns with random entry in net R flagged 38 of 800 rows as winners. Wider stops pay fewer R for the same spread. A control placed before its pattern also trades through bars the pattern was selected on, and loses up to 0.56R on pure noise. With both fixed, 1 row in 800 passes: what a 5% familywise error rate predicts.

The other half is power. When a known edge is planted, an advantage of 0.10R over random entry is caught 88% of the time. That matches the detection limit each leaderboard row now reports, so "no edge" comes with a size: the frequent patterns cannot be hiding an advantage much larger than 0.1R. Read the power study. Run it yourself

No API key or download is needed:

pip install git+https://github.com/dpologdvinity/stock-analyzer
candlebench demo          # synthetic market, full run, interactive dashboard

The dashboard drills from any leaderboard row to the individual trades, and from a trade to its session's chart. candlebench serve --read-only publishes saved runs without letting visitors start new ones.

Source, method and tests on GitHub. These reports contain statistics only: trades appear as R multiples, never as market prices.
